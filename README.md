# Swann OTT Platform

An over-the-top (OTT) video streaming application built from a Flutter client and a Laravel web application/API.

## Projects

- [`flutter-app/`](flutter-app/README.md) — Flutter client for browsing and watching streaming content.
- [`swann-laravel-web-v2.2.1/`](swann-laravel-web-v2.2.1/README.md) — Laravel web application and backend API.

Each project has its own setup instructions and environment configuration. Start with the README in the project you want to run. Keep local `.env` files and service credentials out of Git; use the provided example environment files as templates.

## Languages

The application interface is configured for English and Bangla (Bengali) in the Flutter and Laravel projects.
